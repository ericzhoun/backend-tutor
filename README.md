# backend-tutor

**Backend System Design — a structured course.** A 15-week self-study syllabus: 6 parts, 11 modules, 23 canonical system-design concepts, 35 production case studies, and a 17-volume field document library (interview runbooks, decision playbooks, incident postmortems, code-review patterns).

**Read it live:** <https://olivistart.com/backend-tutor/> (also served at <https://ericzhoun.github.io/backend-tutor/>)

## What's inside

| File | What it is |
|---|---|
| `index.html` | The full interactive course — detailed lessons per module + 57-question quiz engine (GitHub Pages site) |
| `course.md` | The syllabus/outline in Markdown (module map, labs, reading lists) — the lesson content and quizzes live in `index.html` |

## Course map

- **Part I — Foundations (W1–2):** scaling fundamentals, back-of-the-envelope estimation, load balancing, CDN, API gateway, rate limiting
- **Part II — The Data Layer (W3–5):** database scaling, replication, sharding, partitioning, CAP, consistency models, distributed transactions
- **Part III — Performance & Resilience (W6–7):** caching + invalidation, fault tolerance, idempotency
- **Part IV — Architecture Patterns (W8–9):** queues, microservices vs monoliths, service discovery, leader election
- **Part V — Practice (W10–12):** 35 case studies in 8 themes, the 45-minute interview runbook, capstone
- **Part VI — The Field Manual (W13–15):** incident command + failure shapes + the 02:43 outage case, code review, ADRs & postmortems, decision frameworks, the senior track

Weekly rhythm: Read (3 h) → Diagram from memory (2 h) → Build (3 h) → one-page design doc (1 h).
